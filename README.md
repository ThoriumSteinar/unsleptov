# unsleptov

Кибер/техно портфолио fullstack-разработчика.

**Сайт:** https://thoriumsteinar.github.io/unsleptov/

## Локально

```bash
npm install
npm run dev
```

Открой адрес Vite (обычно `http://localhost:5173`).
